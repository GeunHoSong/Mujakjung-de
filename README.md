# 🦦 무작정 (Mujakjung)

### AI 기반 감정 맞춤형 힐링 여행 추천 서비스

**무작정(Mujakjung)**은 일상에 지치고 번아웃을 경험하는 사람들에게 잠시 쉬어갈 수 있는 여행을 추천하는 AI 기반 여행 서비스입니다.

사용자의 감정과 여행 취향을 분석하고, RAG(검색 증강 생성) 기술을 활용하여 개인에게 맞는 여행지와 일정을 추천하는 것을 목표로 합니다.

> "지친 일상에서 잠시 벗어나, 무작정 떠나보세요."

### 🎯 프로젝트 목표

- AI 기반 개인 맞춤형 힐링 여행 추천
- 사용자의 감정을 고려한 여행지 검색
- 잘 알려지지 않은 숨은 여행지 발굴
- 여행 일정 자동 생성 및 추천
- 누구나 편하게 이용할 수 있는 여행 서비스 구현
